# Dream Book Shop Data Analysis

A Python-based academic data analysis project focused on exploring and analyzing a book dataset using Pandas and Matplotlib.

## Project Overview

The project analyzes book-related data to identify useful patterns and insights across publications, authors, languages, publishers and ISBN information.

The notebook demonstrates the use of Python for data loading, cleaning, validation, analysis and visualization.

## Objectives

- Load and inspect book dataset information
- Clean and validate the dataset
- Analyze publication-related information
- Explore authors and languages
- Analyze publishers and ISBN records
- Generate visualizations to communicate findings
- Apply basic object-oriented programming concepts
- Perform basic testing and validation

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Areas

The project includes analysis of:

- Book publications
- Authors
- Languages
- Publishers
- ISBN information
- Dataset quality and validation

## Visualizations

The notebook includes different visualizations, including:

- Bar charts
- Line charts
- Pie charts

These visualizations are used to identify patterns and present analytical findings.
